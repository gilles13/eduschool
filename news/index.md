# Changelog

## eduschool 0.38.0

### Apprendre les mathématiques

- Les identifiants pratiques de notions sont rationalisés par objet
  (`fractions_*`, `fonctions_*`, `statistiques_*`, `probabilites_*`,
  etc.) sans confondre nommage et appartenance à une famille ; les
  identifiants autonomes utiles restent inchangés.
- Le rattachement orphelin `ensembles` est retiré de
  `ensembles_et_intervalles`; `ensembles_nombres`,
  `ensembles_operations` et `intervalles_reels` constituent les trois
  notions actives de cette famille.
- Les fiches commencent, lorsque c’est pertinent, par une définition
  visible « De quoi parle-t-on ? » avant les manipulations.
- Les fiches sur les ensembles distinguent explicitement élément,
  singleton, appartenance, inclusion et ensemble vide, puis ouvrent vers
  les opérations sur les ensembles.
- Une petite porte vers Georg Cantor rappelle que les notions scolaires
  peuvent mener beaucoup plus loin, sans imposer ce détour à l’élève.
- Les en-têtes des fiches sont simplifiés : le type de support devient
  le premier repère visuel, sans titre générique ni thème redondant.
