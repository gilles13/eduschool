# Brevet - atelier des exercices

- `modeles.R` : configurations GEO-A, GEO-B et GEO-C, calculs et controles geometriques.
- `essais.R` : six variantes pour tester les modeles au REPL.

Depuis la racine du depot :

```r
source("inst/brevet/modeles.R")
probleme_A(1, 1 / 4)
probleme_B(2)
```

Pour executer les six exemples : `source("inst/brevet/essais.R")`.

Ces modeles ne produisent pas encore d'enonces rediges, de graphiques ni de documents HTML/PDF.
Les fonctions de rendu et les graphiques restent dans leurs emplacements existants.
