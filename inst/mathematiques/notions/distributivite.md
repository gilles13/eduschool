# Distributivité

La distributivité permet de transformer une expression sans changer sa valeur.

`k(a + b) = ka + kb`

Elle fonctionne dans les deux sens :

- développer : `3(x + 2) = 3x + 6` ;
- factoriser : `3x + 6 = 3(x + 2)`.

Le point important est d’identifier la structure de l’expression avant d’appliquer la règle.
