# Base documentaire pédagogique — V0.9.8

Cette base est volontairement indépendante du code R. Les CSV décrivent les relations ; les fichiers Markdown portent les rappels pédagogiques.

## Principe

`programme -> capacité -> notion -> prérequis -> rappel Markdown -> exercice`

Une notion n'est pas liée à une seule année scolaire. Les tables de programmes et d'applications déterminent le programme applicable ; la documentation décrit les connaissances réutilisables.

## Qualité des fiches

Les fiches donnent un socle de révision homogène. Les fiches les plus utilisées peuvent ensuite être enrichies avec des exemples spécifiques, méthodes détaillées et erreurs fréquentes propres à la notion, sans modifier le code.

`couverture.csv` permet de suivre les capacités détaillées déjà reliées à une notion.
