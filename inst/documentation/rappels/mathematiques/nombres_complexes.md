# Nombres complexes

## Idée centrale
Les nombres complexes prolongent les nombres réels et permettent de traiter ensemble calcul algébrique, trigonométrie et géométrie plane.

## À connaître
Un complexe s’écrit $z=a+ib$ avec $i^2=-1$. Son conjugué est $\bar z=a-ib$ et son module vérifie $|z|^2=z\bar z$. Pour $z\neq0$, on peut écrire $z=r e^{i\theta}$ avec $r=|z|$.

## Méthode
Choisir la forme adaptée : algébrique pour additionner et résoudre des équations simples ; exponentielle pour multiplier, diviser et calculer des puissances ; interprétation géométrique pour les longueurs et angles.

## Exemple
$1+i=\sqrt2 e^{i\pi/4}$, donc $(1+i)^4=4e^{i\pi}=-4$.

## Vérification
Contrôler le module et, lorsque c’est pertinent, replacer le résultat dans le plan complexe.

## Automatismes
Calculer un conjugué, un module, passer d’une forme à l’autre et utiliser $e^{i\theta}=\cos\theta+i\sin\theta$.

## Erreurs fréquentes
Confondre module et argument ; oublier que l’argument est défini modulo $2\pi$ ; développer inutilement une puissance lorsque la forme exponentielle est plus efficace.
