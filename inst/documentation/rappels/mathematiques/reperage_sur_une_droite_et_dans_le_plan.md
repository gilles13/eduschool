# Repérage sur une droite et dans le plan

Repérer un point consiste à associer sa position à un ou plusieurs nombres.

## Sur une droite graduée

Un point est repéré par son abscisse. Les nombres augmentent vers la droite lorsque la graduation est orientée dans le sens usuel.

La distance entre deux nombres $a$ et $b$ est la distance entre les points correspondants ; elle est toujours positive ou nulle.

## Dans un repère du plan

Un point $A$ est repéré par deux coordonnées :

$$A(x;y).$$

- $x$ est l'abscisse ;
- $y$ est l'ordonnée.

On lit d'abord horizontalement, puis verticalement.

## Exemple

Le point $A(-2;3)$ se trouve 2 unités à gauche de l'origine et 3 unités au-dessus.

## Méthode pour placer un point

1. partir de l'origine ;
2. se déplacer selon l'abscisse ;
3. puis selon l'ordonnée ;
4. vérifier le signe de chaque coordonnée.

## Erreurs fréquentes

- inverser abscisse et ordonnée ;
- oublier le signe négatif ;
- supposer que les deux axes utilisent nécessairement la même unité graphique.
