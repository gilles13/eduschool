# Parallélogrammes

Un parallélogramme est un quadrilatère dont les côtés opposés sont parallèles deux à deux.

## Propriétés

Dans un parallélogramme :

- les côtés opposés sont parallèles ;
- les côtés opposés ont la même longueur ;
- les diagonales se coupent en leur milieu ;
- les angles opposés ont la même mesure.

## Reconnaître un parallélogramme

Pour démontrer qu'un quadrilatère est un parallélogramme, il suffit notamment de montrer, selon les données disponibles, que :

- ses côtés opposés sont parallèles deux à deux ;
- ses diagonales ont le même milieu ;
- une paire de côtés opposés est à la fois parallèle et de même longueur.

## Exemple de raisonnement

Si les diagonales $[AC]$ et $[BD]$ d'un quadrilatère $ABCD$ se coupent en leur milieu, alors $ABCD$ est un parallélogramme.

## Cas particuliers

Rectangle, losange et carré sont des parallélogrammes particuliers. Ils possèdent donc toutes les propriétés des parallélogrammes, plus des propriétés supplémentaires.

## Erreurs fréquentes

- croire qu'un parallélogramme doit être « penché » ;
- utiliser une propriété dans le mauvais sens sans connaître une réciproque adaptée ;
- conclure à partir d'une figure qui semble parallèle sans justification.
