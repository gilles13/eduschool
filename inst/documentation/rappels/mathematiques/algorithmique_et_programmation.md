# Algorithmique et programmation

Un algorithme est une suite finie et ordonnée d'instructions permettant d'obtenir un résultat ou de réaliser une tâche.

## Instructions et séquences

Une séquence est exécutée dans un ordre précis. Modifier l'ordre des instructions peut modifier le résultat.

## Variables

Une variable mémorise une valeur susceptible d'évoluer pendant l'exécution. Une affectation remplace l'ancienne valeur par une nouvelle.

Exemple : si `x` vaut 4 puis qu'on effectue `x = x + 3`, alors `x` vaut ensuite 7.

## Conditions

Une condition permet de choisir entre plusieurs actions : « si … alors … sinon … ».

## Boucles

Une boucle répète une ou plusieurs instructions :

- un nombre de fois connu ;
- ou tant qu'une condition reste vraie.

## Concevoir un algorithme

1. identifier les données d'entrée ;
2. préciser le résultat attendu ;
3. décomposer la tâche en actions simples ;
4. tester sur un cas facile ;
5. vérifier les cas particuliers.

## Erreurs fréquentes

- confondre la variable avec sa valeur actuelle ;
- créer une boucle qui ne peut jamais s'arrêter ;
- oublier l'ordre d'exécution ;
- tester uniquement un seul exemple et conclure trop vite que l'algorithme est correct.
