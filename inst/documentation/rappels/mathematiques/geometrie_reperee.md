# Géométrie repérée

## Repère du plan

Dans un repère, un point \(A\) est décrit par ses coordonnées :

\[
A(x_A;y_A).
\]

L'abscisse \(x_A\) se lit horizontalement et l'ordonnée \(y_A\) verticalement.

## Milieu d'un segment

Le milieu \(M\) du segment \([AB]\), avec

\[
A(x_A;y_A),\qquad B(x_B;y_B),
\]

a pour coordonnées :

\[
M\left(
\frac{x_A+x_B}{2};
\frac{y_A+y_B}{2}
\right).
\]

### Exemple

Pour \(A(-2;3)\) et \(B(6;7)\) :

\[
M\left(
\frac{-2+6}{2};
\frac{3+7}{2}
\right)
=
M(2;5).
\]

## Distance entre deux points

Dans un repère orthonormé :

\[
AB
=
\sqrt{(x_B-x_A)^2+(y_B-y_A)^2}.
\]

Cette formule est une application du théorème de Pythagore.

### Exemple

Pour \(A(1;2)\) et \(B(4;6)\) :

\[
AB
=
\sqrt{(4-1)^2+(6-2)^2}
=
\sqrt{9+16}
=
5.
\]

## Déplacement et vecteur

Le déplacement de \(A\) vers \(B\) est décrit par :

\[
\overrightarrow{AB}
=
(x_B-x_A\,;\,y_B-y_A).
\]

Avec \(A(1;2)\) et \(B(4;6)\) :

\[
\overrightarrow{AB}=(3;4).
\]

Deux vecteurs ayant les mêmes coordonnées décrivent le même déplacement.

## Tester une configuration

Les coordonnées permettent de démontrer des propriétés sans mesurer la figure.

Par exemple, pour montrer qu'un quadrilatère a des diagonales de même milieu, on calcule les coordonnées des deux milieux. Si elles sont identiques, les diagonales se coupent en leur milieu.

## Automatismes à maîtriser

- placer et lire un point dans un repère ;
- calculer les coordonnées d'un milieu ;
- calculer une différence de coordonnées avec les bons signes ;
- déterminer les coordonnées d'un vecteur ;
- appliquer la formule de distance dans un repère orthonormé.

## Erreurs fréquentes

- inverser abscisse et ordonnée ;
- calculer \(x_A-x_B\) pour une coordonnée du vecteur \(\overrightarrow{AB}\) au lieu de \(x_B-x_A\) ;
- oublier les carrés dans la formule de distance ;
- utiliser la formule de distance comme si elle était valable dans n'importe quel repère non orthonormé ;
- arrondir trop tôt une racine carrée.

## Pour réviser

Choisir trois points à coordonnées entières, les placer, calculer un milieu, un vecteur et une distance, puis vérifier les résultats graphiquement.
