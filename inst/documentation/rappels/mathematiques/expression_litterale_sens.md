# Comprendre une expression littérale

Une lettre peut représenter un nombre dont la valeur est connue, inconnue ou variable selon le contexte.

- `3x` signifie `3 × x`.
- Si `x = 4`, alors `3x + 2 = 14`.
- Une expression littérale décrit un calcul sans imposer une valeur particulière à la lettre.

L’objectif est d’abord de lire correctement l’expression avant de chercher à la transformer.
