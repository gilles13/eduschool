# Double distributivité

La double distributivité permet de développer le produit de deux sommes ou de deux différences.

Chaque terme du premier facteur multiplie chaque terme du second facteur.

Après le développement, on réduit l'expression en regroupant les termes de même nature.

Il est utile d'écrire les produits intermédiaires avant de réduire pour éviter les erreurs de signe.
