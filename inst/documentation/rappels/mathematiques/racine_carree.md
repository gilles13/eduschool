# Racine carrée

## Idée centrale

Pour un nombre positif ou nul \(a\), \(\sqrt a\) désigne **l'unique nombre positif ou nul dont le carré vaut \(a\)** :

\[
(\sqrt a)^2=a.
\]

Par exemple :

\[
\sqrt{49}=7
\]

car \(7^2=49\).

Dans le cadre des nombres réels, \(\sqrt a\) n'est définie que pour \(a\geq0\).

## Carrés parfaits à connaître

Il est utile de connaître :

\[
1^2=1,\ 2^2=4,\ 3^2=9,\ 4^2=16,\ 5^2=25,
\]

\[
6^2=36,\ 7^2=49,\ 8^2=64,\ 9^2=81,\ 10^2=100.
\]

Ainsi, par exemple, \(\sqrt{81}=9\).

## Encadrer une racine carrée

Pour encadrer \(\sqrt{30}\), on remarque que

\[
25<30<36.
\]

Donc :

\[
5<\sqrt{30}<6.
\]

Une calculatrice peut ensuite donner une valeur approchée si elle est demandée.

## Simplifier une racine

Lorsqu'un facteur est un carré parfait :

\[
\sqrt{72}
=
\sqrt{36\times2}
=
6\sqrt2.
\]

Cette transformation repose sur

\[
\sqrt{ab}=\sqrt a\,\sqrt b
\]

pour \(a\geq0\) et \(b\geq0\).

## Exemple travaillé

Calculer la longueur \(c\) d'un segment dont le carré vaut 125 :

\[
c^2=125.
\]

Comme une longueur est positive :

\[
c=\sqrt{125}
=\sqrt{25\times5}
=5\sqrt5.
\]

Avec une calculatrice :

\[
c\approx11{,}18.
\]

On conserve \(5\sqrt5\) comme valeur exacte si aucune approximation n'est demandée.

## Automatismes à maîtriser

- reconnaître les carrés parfaits usuels ;
- passer de \(x^2=a\) à \(x=\sqrt a\) lorsqu'on sait que \(x\geq0\) ;
- encadrer une racine entre deux entiers ;
- distinguer une valeur exacte d'une valeur approchée.

## Erreurs fréquentes

- écrire \(\sqrt{49}=\pm7\) : la racine carrée \(\sqrt{49}\) vaut 7 ;
- confondre \(\sqrt{a+b}\) avec \(\sqrt a+\sqrt b\), ce qui est faux en général ;
- remplacer trop tôt une racine par une valeur décimale approchée ;
- oublier qu'une longueur ne peut pas être négative.

## Pour réviser

Sans calculatrice, calculer \(\sqrt{16}\), \(\sqrt{64}\), \(\sqrt{100}\), puis encadrer \(\sqrt{20}\), \(\sqrt{50}\) et \(\sqrt{90}\) entre deux entiers consécutifs.
