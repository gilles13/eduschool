## QUAD_RECT_001 / notion

Quadrilatères : raisonner avec les propriétés

## QUAD_RECT_001 / rappel

Le dessin suggère. Le codage donne. Les propriétés permettent de déduire.

## QUAD_RECT_001 / enonce

ABCD est un parallélogramme. Le codage indique que l'angle DAB est droit. Que peux-tu en déduire ?

## QUAD_RECT_001 / reponse

ABCD est un rectangle

## QUAD_RECT_001 / proposition_2

ABCD est un losange

## QUAD_RECT_001 / proposition_3

ABCD est forcément un carré

## QUAD_RECT_001 / proposition_4

On ne peut rien déduire

## QUAD_RECT_001 / feedback_1

Un parallélogramme qui possède un angle droit est un rectangle. Le dessin n'a pas besoin de ressembler à un rectangle.

## QUAD_RECT_001 / feedback_2

Un angle droit ne suffit pas à montrer que les quatre côtés ont la même longueur.

## QUAD_RECT_001 / feedback_3

Pour conclure carré, il manque encore une propriété de losange.

## QUAD_RECT_001 / feedback_4

Le codage de l'angle droit apporte justement l'information qui permet de conclure.

## QUAD_CARRE_001 / feedback_3

C'est bien un losange, mais le codage de l'angle droit permet d'aller plus loin.

Le dessin aide à se repérer. Les définitions et les propriétés permettent de raisonner.

## CERC_RAYON_001 / reponse

rayon

## CERC_RAYON_001 / proposition_2

diamètre

## CERC_RAYON_001 / proposition_3

corde

## CERC_RAYON_001 / proposition_4

tangente

## CERC_RAYON_001 / feedback_1

[OA] relie le centre O à un point A du cercle : c'est un rayon.

## CERC_RAYON_001 / feedback_2

Un diamètre relie deux points du cercle et passe par le centre.

## CERC_RAYON_001 / feedback_3

Une corde relie deux points du cercle ; ici O est le centre et non un point du cercle.

## CERC_RAYON_001 / feedback_4

Une tangente est une droite qui touche le cercle en un seul point.

Deux droites perpendiculaires se coupent en formant un angle droit.

## DROIT_PERP_001 / rappel

Le dessin peut suggérer. Une information donnée ou un codage permet d'affirmer.

Le petit carré code un angle droit entre les droites (d) et (Δ). Que peut-on affirmer ?

## DROIT_PERP_001 / reponse

Les droites (d) et (Δ) sont perpendiculaires

## DROIT_PERP_001 / proposition_2

Les droites (d) et (Δ) sont parallèles

## DROIT_PERP_001 / proposition_3

Les droites (d) et (Δ) ont la même longueur

## DROIT_PERP_001 / proposition_4

## DROIT_PERP_001 / feedback_1

Le petit carré code un angle droit : les droites (d) et (Δ) sont donc perpendiculaires.

## DROIT_PERP_001 / feedback_2

Des droites parallèles ne se coupent pas dans le plan euclidien ; ici le codage montre un angle droit.

## DROIT_PERP_001 / feedback_3

Une droite n'a pas de longueur : elle est illimitée.

## DROIT_PERP_001 / feedback_4

Le codage apporte précisément l'information nécessaire pour conclure.

## DROIT_PAR_001 / proposition_2

## DROIT_PAR_001 / proposition_3

## DROIT_PAR_001 / feedback_3

## DROIT_PAR_001 / feedback_4

## DROIT_DED_001 / proposition_2

Les droites (d) et (d') sont perpendiculaires

## DROIT_DED_001 / proposition_3

## DROIT_DED_001 / proposition_4

## DROIT_DED_001 / feedback_1

Les droites (d) et (d') sont perpendiculaires à (Δ).
