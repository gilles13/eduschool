# L'essentiel : Indicateurs statistiques

::: {.edu-definition}
**De quoi parle-t-on ?**

Un indicateur statistique résume un aspect d’une série de données par un nombre : position, valeur moyenne ou dispersion.
:::

## Principe

Moyenne : somme des valeurs divisée par leur nombre. Médiane : valeur qui partage une série ordonnée en deux groupes. Étendue : maximum − minimum.

## Méthode

Pour des effectifs : $\bar{x}=\frac{\sum n_i x_i}{\sum n_i}$.

## Exemple

Pour 2 ; 4 ; 4 ; 5 ; 10 : moyenne 5, médiane 4, étendue 8.

## Vérification

La moyenne est comprise entre les extrêmes ; l’étendue vaut 8.

## À retenir

Comparer plusieurs indicateurs avant de conclure sur une série.
