# Cercle trigonométrique : synthèse

- Cercle de centre $O$ et de rayon 1, orienté dans le sens inverse des aiguilles d'une montre.
- Pour un angle $x$, $M=(\cos x,\sin x)$.
- Un tour : $360° = 2\pi$ radians ; un demi-tour : $180° = \pi$ radians.
- Angles remarquables : $0°$, $30°$, $45°$, $60°$, $90°$ correspondent à $0$, $\pi/6$, $\pi/4$, $\pi/3$, $\pi/2$ radians.
- $\cos^2 x + \sin^2 x = 1$.
