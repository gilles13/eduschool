# Trigonométrie du triangle rectangle — l'essentiel

**Condition :** on travaille dans un triangle rectangle. Identifier d'abord l'angle étudié.

<!-- graphique: trigonometrie_triangle_rectangle -->

Pour l'angle $\widehat{ABC}$ dans $ABC$ rectangle en $A$ :

$$\sin(\widehat{ABC})=\frac{AC}{BC}\quad
\cos(\widehat{ABC})=\frac{AB}{BC}\quad
\tan(\widehat{ABC})=\frac{AC}{AB}.$$

- **Sinus** : opposé / hypoténuse.
- **Cosinus** : adjacent / hypoténuse.
- **Tangente** : opposé / adjacent.

**Méthode :** identifier l'angle et les deux côtés utiles ; choisir le rapport qui les relie ; écrire l'égalité avec les lettres ; remplacer les données ; isoler l'inconnue.

**Calculatrice :** vérifier le mode **degrés** si l'angle est donné en degrés. Pour trouver un angle à partir d'un rapport, utiliser la fonction réciproque appropriée ($\arcsin$, $\arccos$ ou $\arctan$).

**Pièges :** « adjacent » ne désigne jamais l'hypoténuse ; les côtés opposé et adjacent changent quand on change d'angle.
