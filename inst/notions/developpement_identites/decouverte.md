# Développement avec les identités remarquables


Un même carré peut être calculé de deux manières : aire du carré de côté $a+b$, ou somme des aires $a^2+ab+ab+b^2$. Cela explique **le terme double** $2ab$. Une identité est vraie pour toutes les valeurs admises, pas seulement pour un exemple numérique.

Essaye ensuite le carré d’une différence et le produit de deux expressions conjuguées.
