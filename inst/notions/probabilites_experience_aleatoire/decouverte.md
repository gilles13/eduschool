# Découvrir : Expérience aléatoire et probabilité

::: {.edu-definition}
**De quoi parle-t-on ?**

Une expérience aléatoire a plusieurs résultats possibles sans que l’on sache à l’avance lequel se produira. Une probabilité mesure la chance qu’un événement se réalise.
:::

## Première idée

Lancer un dé : les issues sont 1, 2, 3, 4, 5, 6. « Obtenir un nombre pair » est l’événement {2, 4, 6}.

## Comprendre la méthode

Dans une situation équiprobable, compter toutes les issues puis celles qui réalisent l’événement : $P(A)=\frac{\text{issues favorables}}{\text{issues possibles}}$.

## Vérifier

Une probabilité est toujours comprise entre 0 et 1. 0 correspond à l’impossible ; 1 au certain.

## À essayer

**À essayer 1 — Dé équilibré :** quelle est la probabilité d’obtenir un multiple de 3 ?

## À retenir

Une probabilité porte sur un événement, c’est-à-dire un ensemble d’issues.

## Pour vérifier tes découvertes

**1. Dé équilibré**

Les issues favorables sont 3 et 6 : $P=2/6=1/3$.
