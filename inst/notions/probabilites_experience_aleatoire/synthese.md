# L'essentiel : Expérience aléatoire et probabilité

::: {.edu-definition}
**De quoi parle-t-on ?**

Une expérience aléatoire a plusieurs résultats possibles sans que l’on sache à l’avance lequel se produira. Une probabilité mesure la chance qu’un événement se réalise.
:::

## Principe

En équiprobabilité : $P(A)=\frac{\text{nombre de cas favorables}}{\text{nombre de cas possibles}}$.

## Méthode

Lister les issues ; définir l’événement ; compter ; former le quotient ; simplifier.

## Exemple

Dé : « pair » = {2,4,6}, donc $P=3/6=1/2$.

## Vérification

$0\le P(A)\le1$.

## À retenir

Impossible : 0. Certain : 1. Une chance sur quatre : $1/4=0,25=25\%$.
