# L’essentiel : Trouver un terme manquant avec des fractions

::: {.edu-definition}
**De quoi parle-t-on ?**

Un terme manquant dans une égalité peut être retrouvé en utilisant l’opération inverse.
:::

## Principe

Une opération inverse permet de retrouver le terme manquant, puis l’égalité initiale permet de vérifier.

## Méthode

Isoler la quantité cherchée avec l’opération inverse, puis effectuer le calcul sur les fractions.

## Exemple

$$\square=\frac{5}{6}-\frac{1}{3}=\frac{5}{6}-\frac{2}{6}=\frac{1}{2}.$$

## Vérification

Remplacer la boîte par le résultat : l’égalité initiale doit être vraie.

## À retenir

Une opération inverse permet de retrouver le terme manquant, puis l’égalité initiale permet de vérifier.
