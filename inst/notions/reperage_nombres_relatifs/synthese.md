# L’essentiel : Les nombres relatifs

Un **nombre relatif** peut être positif, négatif ou nul. Sur une droite graduée, les nombres augmentent de gauche à droite.

Deux nombres comme 4 et −4 sont **opposés** : ils ont la même distance à 0 et leur somme vaut 0.

La **valeur absolue** est la distance à 0 : |−4| = |4| = 4.

**À retenir :** parmi deux nombres négatifs, celui qui est le plus proche de 0 est le plus grand. Par exemple −2 > −7.
