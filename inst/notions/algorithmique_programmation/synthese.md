# L'essentiel : Algorithmique et programmation

::: {.edu-definition}
**De quoi parle-t-on ?**

Un **algorithme** est une suite d'instructions précises permettant d'accomplir une tâche. Un **programme** est une traduction de ces instructions dans un langage exécutable.
:::

## Principe

Un algorithme enchaîne des instructions ; l'ordre, les tests et les répétitions déterminent le résultat.

## Méthode

Pour suivre un programme, partir des valeurs initiales et mettre à jour chaque variable après chaque instruction. Pour vérifier, essayer plusieurs entrées.

**Indentation :** décaler des instructions vers la droite permet de repérer celles qui appartiennent à une boucle ou à une condition. Dans Scratch, ce rôle est assuré par l'emboîtement des blocs.

**Lecture des cadres :** dans « Répéter », seules les instructions à l'intérieur du cadre sont répétées. Les instructions situées à l'extérieur ne le sont pas. Dans « Si », seules les instructions du cadre sont exécutées lorsque la condition est vraie.

## Exemple

Avec le programme « multiplier par 3 puis ajouter 2 », l'entrée 4 produit **14**.

## Vérification

Comparer la sortie à un calcul manuel, et tester aussi d'autres valeurs.

## À retenir

Variable : valeur mémorisée. Condition : choix selon un test. Boucle : répétition. Trace : valeurs successives des variables.
