# Réviser : terme manquant dans une fraction

**Règle :** Pour retrouver un terme manquant dans une somme de fractions, on utilise la soustraction.

**Exemple corrigé :** □ + 1/3 = 5/6 donne □ = 5/6 − 2/6 = 1/2.
