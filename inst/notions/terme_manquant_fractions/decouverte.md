# Découvrir : terme manquant dans une fraction

Pour retrouver un terme manquant dans une somme de fractions, on utilise la soustraction.

## Observons

□ + 1/3 = 5/6 donne □ = 5/6 − 2/6 = 1/2.

**À essayer 1 — À ton tour :** Trouve le nombre manquant dans $\square+1/4=3/4$.

## Pour vérifier tes découvertes

**1. À ton tour.** $\square=3/4-1/4=2/4=1/2$.
