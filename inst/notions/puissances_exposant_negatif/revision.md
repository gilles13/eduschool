# Réviser : Puissances d'exposant négatif

Trois repères permettent de passer progressivement des exposants positifs aux exposants négatifs :

$$a^1=a,\qquad a^0=1,\qquad a^{-1}=\frac1a\quad(a\neq0).$$

Plus généralement, pour $n>0$ :

$$a^{-n}=\frac{1}{a^n}.$$

Pour une même base non nulle :

$$a^m\times a^n=a^{m+n},\qquad \frac{a^m}{a^n}=a^{m-n}.$$

**Réflexes :**

1. $a^1=a$ : l'exposant 1 laisse la base inchangée.
2. $10^{-3}=1/10^3=0{,}001$.
3. $3^{-2}=1/9$ : un exposant négatif ne signifie pas que le résultat est négatif.
4. $3^{-2}\times3^5=3^3$ : on additionne les exposants.
5. $10^{-2}/10^3=10^{-5}$ : on soustrait les exposants.

**Piège classique :** $4^{-1}=1/4$, et non $-4$.
