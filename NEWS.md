# eduschool 0.38.0

## Apprendre les mathématiques

- Les fiches commencent, lorsque c’est pertinent, par une définition visible « De quoi parle-t-on ? » avant les manipulations.
- Les fiches sur les ensembles distinguent explicitement élément, singleton, appartenance, inclusion et ensemble vide, puis ouvrent vers les opérations sur les ensembles.
- Une petite porte vers Georg Cantor rappelle que les notions scolaires peuvent mener beaucoup plus loin, sans imposer ce détour à l’élève.
- Les en-têtes des fiches sont simplifiés : le type de support devient le premier repère visuel, sans titre générique ni thème redondant.
