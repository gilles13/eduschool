# Lister les fiches de revision disponibles

Lister les fiches de revision disponibles

## Usage

``` r
fiches_revision(niveau_id = NULL, famille = NULL, type = NULL)
```

## Arguments

- niveau_id:

  Niveau scolaire facultatif.

- famille:

  Famille facultative, par identifiant ou libelle.

- type:

  Type facultatif : \`"THEMATIQUE"\` ou \`"ESSENTIEL"\`.

## Value

Un data.frame de fiches disponibles.
