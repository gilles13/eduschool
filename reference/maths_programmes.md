# Programmes de mathematiques documentes dans la sauvegarde v1

Programmes de mathematiques documentes dans la sauvegarde v1

## Usage

``` r
maths_programmes(niveau = NULL)
```

## Arguments

- niveau:

  Identifiant scolaire, par exemple "6E" ou "TG" ; NULL pour tous.

## Value

Les programmes et leurs applications connues, sans presumer de leur
vigueur actuelle.
