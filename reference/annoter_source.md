# Ajouter la source a un graphique ggplot2

Ajouter la source a un graphique ggplot2

## Usage

``` r
annoter_source(graphique, donnees)
```

## Arguments

- graphique:

  Objet \`ggplot\`.

- donnees:

  Donnees portant l'attribut de provenance eduschool.

## Value

Le graphique avec une legende de source (\`caption\`).
