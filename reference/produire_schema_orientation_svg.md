# Produire le schema des principales orientations

Le SVG est genere directement depuis les tables d'orientation du
package.

## Usage

``` r
produire_schema_orientation_svg(fichier = NULL)
```

## Arguments

- fichier:

  Chemin du SVG. Si \`NULL\`, utilise un fichier temporaire.

## Value

Invisiblement, le chemin absolu du SVG produit.
