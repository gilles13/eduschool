# Enseignements optionnels au lycee general

Les enseignements optionnels completent le parcours mais ne doivent pas
etre confondus avec les enseignements de specialite.

## Usage

``` r
enseignements_optionnels_lycee(niveau_id = "1G", version_id = "2026_2027")
```

## Arguments

- niveau_id:

  \`"1G"\` ou \`"TG"\`.

- version_id:

  Version scolaire. Par defaut \`"2026_2027"\`.

## Value

Un data.frame avec libelle et volume horaire.
