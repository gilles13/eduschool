# Lire les questions d'une notion pilote

Lire les questions d'une notion pilote

## Usage

``` r
questions(notion, niveau = "", .membre = FALSE)
```

## Arguments

- notion:

  Identifiant d'une notion ou d'une famille.

- niveau:

  Niveau scolaire facultatif pour filtrer les notions d'une famille.

- .membre:

  Indicateur interne de chargement d'une notion membre.
