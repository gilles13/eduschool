# Jalons dates d'une campagne Parcoursup

Le calendrier est modelise sous forme evenementielle : ajouter un jalon
a une nouvelle campagne ne necessite donc aucune modification du schema.

## Usage

``` r
parcoursup_calendrier(campagne_id = "PS2026")
```

## Arguments

- campagne_id:

  Identifiant de campagne, par defaut \`PS2026\`.

## Value

Un data.frame ordonne des jalons dates de la campagne.
