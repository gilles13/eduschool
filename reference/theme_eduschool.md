# Theme ggplot2 eduschool

Applique une mise en forme sobre et coherente avec les fiches. La
fonction retourne un objet theme ggplot2 et laisse les donnees et
geometries libres.

## Usage

``` r
theme_eduschool(cycle_id = "NEUTRE", base_size = 11)
```

## Arguments

- cycle_id:

  Cycle dont la couleur sert d'accent.

- base_size:

  Taille de base du texte.

## Value

Un objet \`theme\` de ggplot2.
