# Generer une fiche de revision thematique

Generer une fiche de revision thematique

## Usage

``` r
generer_revision(niveau_id, famille)
```

## Arguments

- niveau_id:

  Identifiant du niveau, par exemple \`"2GT"\`.

- famille:

  Famille de connaissances, par exemple \`"GEOMETRIE"\`.

## Value

Un objet \`eduschool_revision\` pret a etre inspecte ou rendu.
