# Gabarits d'exercices d'examen

Consulte la banque relationnelle de gabarits d'exercices d'examen.

## Usage

``` r
gabarits_examen(examen_code = NULL, partie_type = NULL, domaine = NULL, statut = "ACTIF")
```

## Arguments

- examen_code:

  Code d'examen facultatif.

- partie_type:

  Type de partie facultatif.

- domaine:

  Domaine mathematique facultatif.

- statut:

  Statut des gabarits. Par defaut, seuls les gabarits actifs sont
  retournes.

## Value

Un data.frame.
