# Methodes mobilisees par les types d'exercices mathematiques

Methodes mobilisees par les types d'exercices mathematiques

## Usage

``` r
methodes_exercices_math(type_exercice_id = NULL, methode_id = NULL)
```

## Arguments

- type_exercice_id:

  Type d'exercice facultatif.

- methode_id:

  Methode facultative.
