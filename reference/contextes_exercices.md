# Contextes d'exercices composes

Les contextes decrivent l'habillage semantique des exercices sans
stocker d'enonces complets. Un meme gabarit mathematique peut ainsi etre
instancie dans plusieurs situations realistes.

## Usage

``` r
contextes_exercices(famille_contexte = NULL, statut = "ACTIF")
```

## Arguments

- famille_contexte:

  Famille de contexte facultative.

- statut:

  Statut des contextes. Par defaut, seuls les actifs sont retournes.

## Value

Un data.frame.
