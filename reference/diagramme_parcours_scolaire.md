# Produire le diagramme des parcours scolaires

Raccourci vers \`produire_diagramme_html("parcours_scolaire", ...)\`.

## Usage

``` r
diagramme_parcours_scolaire(fichier = NULL, ouvrir = FALSE)
```

## Arguments

- fichier:

  Chemin du fichier HTML à produire. Si \`NULL\`, un fichier temporaire
  est cree.

- ouvrir:

  Ouvrir le fichier avec l'application associée après sa création.

## Value

Invisiblement, le chemin absolu du fichier HTML produit.
