# Resume des controles d'integrite

Resume des controles d'integrite

## Usage

``` r
resume_controles_si(niveau = c("complet", "structure", "semantique"))
```

## Arguments

- niveau:

  Portee des controles : \`"complet"\`, \`"structure"\` ou
  \`"semantique"\`.

## Value

Un data.frame agrege par type de controle.
