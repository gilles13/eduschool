# Libelle d'un niveau scolaire

Retourne le libelle associe a un identifiant de niveau. Si le
referentiel n'est pas disponible ou si l'identifiant n'est pas trouve,
l'identifiant fourni est retourne tel quel.

## Usage

``` r
libelle_niveau(niveau_id)
```

## Arguments

- niveau_id:

  Identifiant du niveau scolaire.

## Value

Une chaine de caracteres contenant le libelle du niveau.
