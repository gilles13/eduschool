# Gabarits d'exercices composes

Gabarits d'exercices composes

## Usage

``` r
gabarits_exercices_composes(
  examen_code = NULL,
  partie_type = NULL,
  statut = "ACTIF"
)
```

## Arguments

- examen_code:

  Code d'examen facultatif.

- partie_type:

  Type de partie facultatif.

- statut:

  Statut des gabarits. Par defaut, seuls les actifs sont retournes.

## Value

Un data.frame.
