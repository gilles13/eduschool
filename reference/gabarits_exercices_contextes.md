# Contextes compatibles avec un gabarit compose

Contextes compatibles avec un gabarit compose

## Usage

``` r
gabarits_exercices_contextes(gabarit_compose_id = NULL, statut = "ACTIF")
```

## Arguments

- gabarit_compose_id:

  Identifiant du gabarit compose.

- statut:

  Statut des relations. Par defaut, seules les relations actives sont
  retournees.

## Value

Un data.frame joignant relation et contexte semantique.
