# Produire la cheatsheet eduschool

Genere la cheatsheet HTML autonome, avec ses deux logos integres.

## Usage

``` r
produire_cheatsheet(fichier = NULL, ouvrir = TRUE)
```

## Arguments

- fichier:

  Fichier HTML de sortie. Par defaut, dans un dossier temporaire.

- ouvrir:

  Ouvrir le resultat dans le navigateur.

## Value

Invisiblement, le chemin absolu du HTML produit.
