# Notions documentées pour un niveau

Notions documentées pour un niveau

## Usage

``` r
notions_niveau(niveau_id, discipline_id = NULL, version_id = "2026_2027")
```

## Arguments

- niveau_id:

  Identifiant du niveau, par exemple \`6E\`.

- discipline_id:

  Discipline facultative.

- version_id:

  Version scolaire, par exemple \`2026_2027\`.
