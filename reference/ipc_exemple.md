# Charger le petit exemple IPC embarque

Charge un petit extrait fige d'une serie officielle de l'Insee. Cet
extrait sert aux tests, aux vignettes et aux exemples reproductibles :
aucun acces reseau n'est effectue.

## Usage

``` r
ipc_exemple()
```

## Value

Un data.frame de classe \`eduschool_donnees\` avec sa provenance.
