# Produire le schema des etapes Parcoursup

Produire le schema des etapes Parcoursup

## Usage

``` r
produire_schema_parcoursup_svg(fichier = NULL)
```

## Arguments

- fichier:

  Chemin du SVG. Si \`NULL\`, utilise un fichier temporaire.

## Value

Invisiblement, le chemin absolu du SVG produit.
