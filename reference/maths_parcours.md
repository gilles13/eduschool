# Parcours des mathematiques du cycle 3 au lycee

Parcours des mathematiques du cycle 3 au lycee

## Usage

``` r
maths_parcours(fichier = NULL, ouvrir = TRUE)
```

## Arguments

- fichier:

  Chemin SVG, PNG ou PDF de sortie, ou NULL pour retourner les donnees.

- ouvrir:

  Ouvrir le fichier apres sa generation (TRUE par defaut).

## Value

Les etapes et liens, ou invisiblement le chemin du SVG genere.
