# Capacités d'un programme

Capacités d'un programme

## Usage

``` r
capacites(niveau_id = NULL, discipline_id = "MAT", version_id = NULL)
```

## Arguments

- niveau_id:

  Niveau scolaire facultatif (\`6E\`, \`5E\`, \`2GT\`, ...).

- discipline_id:

  Discipline, \`MAT\` par défaut.

- version_id:

  Version scolaire facultative, par exemple \`2026_2027\`.
