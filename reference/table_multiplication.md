# Tables de multiplication

Tables de multiplication

## Usage

``` r
table_multiplication(max = 9L, format = "objet", dossier = NULL, ouvrir = TRUE)
```

## Arguments

- max:

  Derniere table et dernier multiplicateur (entier positif).

- format:

  \`"objet"\`, \`"html"\` ou \`"pdf"\`.

- dossier:

  Repertoire de sortie pour HTML/PDF.

- ouvrir:

  Ouvrir le document apres production.

## Value

Une matrice de tables ou, invisiblement, le chemin du document.
