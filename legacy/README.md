# legacy

Ce répertoire conserve l'ancien code R d'eduschool comme **boîte à idées**.

Il ne fait pas partie du package installé, n'est pas chargé par R et n'est pas
une API à maintenir. Son contenu peut être consulté ponctuellement lorsqu'une
ancienne idée mérite d'être reprise.

Règle de reprise : on ne remet pas une ancienne fonction dans `R/` telle quelle
par inertie. On repart du besoin actuel et on réintroduit seulement le code
minimal réellement utile.

Le code actif du package vit dans `R/`.
