# Mathématiques par niveau

Cette page est le point d’entrée rapide vers les **fiches, mémos et
exercices de mathématiques**. Les contenus sont enrichis progressivement
: un niveau peut donc être accessible ici avant que toutes ses fiches
soient disponibles.

Chaque page de classe devient un petit espace de travail autonome :
programme, révision, entraînement et ressources. Les rubriques
apparaissent même lorsque leur contenu est encore en cours
d’enrichissement, afin de conserver une navigation stable dans le temps.

------------------------------------------------------------------------

## Depuis R

La navigation du site est une porte d’entrée ; les données restent
accessibles directement avec l’API du package.

``` r

programme("1G")
fiches_revision("2GT")
concepts_math(niveau_id = "1G")
```
