# Parcours scolaires

Cette vignette présente les parcours scolaires actuellement modélisés
dans `eduschool`. Le schéma est construit à partir des référentiels du
package et sera enrichi à mesure que les voies, séries et orientations
seront détaillées.

![Parcours scolaires modélisés dans
eduschool](../reference/figures/parcours_scolaire.svg)

Parcours scolaires modélisés dans eduschool

Le diagramme HTML interactif correspondant peut être produit avec :

``` r

diagramme_parcours_scolaire(ouvrir = TRUE)
```

La représentation graphique n’est pas une source de vérité indépendante
: elle est une vue des données relationnelles du package.
